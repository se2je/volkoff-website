# Задачи

## Платёжка — Т-Касса (рубли) ⏸ ждём владельца ИП

Код готов (v0.3.x): `apps/api/src/payments/tkassa.ts`, подробности — [PAYMENTS-TKASSA.md](PAYMENTS-TKASSA.md).
Документы передали владельцу сайта / ИП, он оформляет.

**Владелец ИП:**
- [ ] Счёт ИП в Т-Банке — https://www.tbank.ru/business/rko/
- [ ] Заявка на интернет-эквайринг — https://www.tbank.ru/kassa/ (сайт `https://volkoffmvs.com`, подключение через API)
- [ ] ОКВЭД 47.91 у ИП
- [ ] Онлайн-касса для чеков (Т-Чеки в кабинете)
- [ ] Прислать реквизиты: ФИО ИП, ИНН, ОГРНИП, адрес — **нужны до модерации сайта банком**

**Мы:**
- [ ] Вписать реквизиты в `apps/web/src/config/site.ts` → `LEGAL`, выпустить версию
- [ ] Настройки терминала в кабинете https://business.tbank.ru: одностадийная оплата, уведомления HTTP → `https://volkoffmvs.com/api/payments/webhook/tkassa`
- [ ] Тестовые ключи → Vault `apps/volkoff_website`: `TKASSA_TERMINAL_KEY`, `TKASSA_PASSWORD` (+ `TKASSA_TAXATION`, если не УСН «доходы»)
- [ ] Перезапустить деплой в Semaphore, оплатить тестовой картой, проверить статус и письмо
- [ ] Пройти обязательные тест-кейсы в кабинете → боевой терминал → заменить ключи в Vault
- [ ] ⚠️ До **06.03.2027** обновить сертификат Минцифры (`apps/api/certs/README.md`)
